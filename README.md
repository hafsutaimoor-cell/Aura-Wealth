# Aura-Wealth
Aura Wealth is an AI-powered personal finance web app built with Next.js 14 and Tailwind CSS. Featuring a dark-mode glassmorphism UI, it tracks net worth, cash flows, and savings goals via an interactive AI voice assistant.

**Key Features**
AI Voice Assistant Widget: Interactive voice command interface allowing users to log transactions and query financial insights instantly.

Interactive Financial Dashboard: Real-time net worth tracking, monthly income/expense summary cards, and dynamic spending trends charts powered by Recharts.

Transaction Management: Clean, searchable, and categorized table views with full CRUD operations for financial records.

Wealth & Savings Goals: Milestone trackers and progress bars for target savings (e.g., Emergency Fund, Investments).

Modern Tech Stack: Developed using Next.js 14, TypeScript, Tailwind CSS, and Lucide React icons.
